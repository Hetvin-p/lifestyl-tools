# LifeStyl operator tools

Static pages for LifeStyl operators, served by GitHub Pages.

- `index.html` — **Menu Seed Builder**: checks a filled `menu-import` workbook on your phone and uploads it to a business's catalogue through the `import-catalogue` edge function.

The source of truth is `tools/menu-import/web/menu-seed-builder.html` in the `Lifestyl_Business` repo; run `tools/menu-import/deploy-page.sh` there to publish a change here. Nothing in this repo is secret — the operator key is typed in by the person using the page.
